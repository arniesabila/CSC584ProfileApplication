Profile Web Application
Project Overview

This is a simple Java Web Application that allows users to:

Fill in their personal information using an HTML form

Submit the data to a Servlet for processing

Display the submitted details neatly on a JSP page

This project demonstrates the Servlet-JSP MVC flow without using a database.


Features

User-friendly HTML form to collect:

Name

Student ID

Program

Email

Hobbies

Short self-introduction

Servlet (ProfileServlet) to process the submitted data

JSP (ProfileDisplay.jsp) to display the user profile dynamically
