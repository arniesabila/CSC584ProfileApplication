Profile Web Application

Project Overview
This is a simple Java Web Application that allows users to:
1. Fill in their personal information using an HTML form
2. Submit the data to a Servlet for processing
3. Display the submitted details neatly on a JSP page
4. This project demonstrates the Servlet-JSP MVC flow without using a database.
   


Features
1. User-friendly HTML form to collect:
2. Name
3. Student ID
4. Program
5. Email
6. Hobbies
7. Short self-introduction
8. Servlet (ProfileServlet) to process the submitted data
9. JSP (ProfileDisplay.jsp) to display the user profile dynamically
